What this course is about

  • You will use a robot arm to help elderly people at an elderly center.
  • Each group gets the same starter setup:
    • Robot arm mounted on a table
    • Top-down camera pointing at the table
    • A VLM (vision-language model) that plans, finds objects, and does pick-and-place
  • Your job is to create a custom use case by:
    • Tuning the VLM system prompt, or
    • Modifying the underlying code (for advanced groups)

Starter hardware / software

Component What it does
Robot arm on table Physically picks and places objects
Top-down camera Sees the workspace
VLM planner Looks at the image and decides what to do
System prompt Tells the VLM how to behave
Code base Lets advanced groups change control logic

Note

What makes a good use case?

  • Helpful: solves a real problem for elderly people.
  • Simple: can be done with pick-and-place and one or two custom parts.
  • Safe: no sharp or heavy parts near the user.
  • Testable: you can demo it clearly in 3 minutes.

Examples to get you thinking:

  • Sorting pills or snacks into cups
  • Handing a water bottle or remote control
  • Moving game pieces for a simple tabletop activity

Your deliverables

  1. Lesson 4 — Group plan (idea + rough hardware needs).
  2. Lesson 5 — STL files for first 3D print.
  3. Lesson 6 — Updated STL files after testing.
  4. Lesson 7 & 8 — Working demos and feedback notes.
  5. Lesson 9 — Final presentation.

Key mindset

  • Iterate fast: design → print → test → improve.
  • Listen to the elderly — they are your real users.
  • Ask instructors for help early.
  • Have fun and be creative!
